# Player name and knockdown direction fix

- The champion selection screen now has editable Player 1 and Player 2 name fields.
- Custom names are used in the fighter labels, health HUD, and winner banner during the match.
- Blue knockdowns animate toward the left edge of the arena.
- Red knockdowns animate toward the right edge of the arena.
- Existing arena, fighter artwork, power choices, and game flow are retained.

## Apply the update

Replace the files in the existing GitHub repository with the files from this ZIP, commit the changes, and push to `main`. Netlify should then build from the updated `main` branch.
